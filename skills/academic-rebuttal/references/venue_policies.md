# Venue-Specific Rebuttal Policies

> **Policies change yearly.** Always verify against that year's official CFP/author-instructions page. Data below reflects 2025–2026 cycle where available.
>
> **Facts last verified 2026-11-12** against the official pages: NeurIPS 2025 FAQ and 2026 Main Track Handbook; ICML 2026 Reviewer/Author Instructions; ICLR 2026 Author Guide and ICLR 2027 CFP/Dates; AAAI-27 submission instructions; USENIX OSDI '25/'26/'27, NSDI '25/'26/'27 and FAST '27 CFPs; SIGCOMM 2025/2026/2027 CFPs; MobiCom 2026/2027 CFPs; SOSP 2025/2026 CFPs. Rules change every cycle — confirm on the live CFP / response form before relying on any cap. **If you have no network access,** use the stored values below, state which cycle each was verified for, and tell the user to confirm on the live CFP / response form.

## OpenReview Venues

### NeurIPS 2025
| Field | Value |
|-------|-------|
| Platform | OpenReview |
| Response granularity | Per-review (global rebuttal removed) |
| Character limit | **10,000 characters** per review response |
| Format | Markdown text only |
| File uploads | Not allowed |
| Links | Not allowed (except AC-mediated code-link scenario) |
| Revised paper upload | Not allowed until camera-ready |
| Visibility timing | Rebuttals revealed to reviewers/ACs **at end of rebuttal window** (not immediately) |
| New results | Allowed: FAQ — "Can the rebuttal include new results? Yes, however your original submission will serve as the basis for the reviewers' (and ACs') acceptance recommendations." |
| Discussion phase | Reviewer-author discussion window follows rebuttal window |
| Source | neurips.cc/Conferences/2025/PaperInformation/NeurIPS-FAQ |

### NeurIPS 2026
| Field | Value |
|-------|-------|
| Platform | OpenReview |
| Response granularity | Per-review: use the "Rebuttal" button on each review and check the message "readers" |
| Character limit | **10,000 characters** per review |
| Format | Plain text with OpenReview-supported markdown; no additional files |
| Links | "Do not use links in any part of the response"; only exception: if reviewers asked for code, send an anonymized link to the AC in an Official Comment |
| New results | Allowed: "These responses can include new results, however your original submission will serve as the basis for the reviewers' (and ACs') acceptance recommendations." |
| Revised paper | Authors "may not submit revisions of their paper or supplemental material" during the response period |
| Phases | (1) authors view reviews and meta-reviews and write an initial response, hidden from ACs/reviewers until that period ends; (2) author-reviewer-AC discussion, where authors may respond to further questions; (3) reviewer-AC discussion, not visible to authors |
| Dates (Main Conference) | Reviews released to authors **Jul 22, 2026**; author+reviewer+AC discussion **Jul 27 – Aug 3, 2026**; reviewer+AC discussion Aug 3 – Aug 10, 2026; author notifications Sep 24, 2026 (all AoE) |
| Anti-manipulation | The handbook says "attempts at prompt injections as well as other attempts to manipulate reviewing is strictly prohibited" — never put text aimed at steering automated reviewers in a response |
| Sources | https://neurips.cc/Conferences/2026/MainTrackHandbook; https://neurips.cc/Conferences/2026/Dates |

### ICML 2026
| Field | Value |
|-------|-------|
| Platform | OpenReview |
| Submission format | **8 pages** for the main paper; accepted papers receive **1 extra camera-ready page** |
| Review model | Double-blind; author list frozen at the Jan 23 abstract deadline |
| Deadlines | Abstract: **Jan 23, 2026 AoE**; paper: **Jan 28, 2026 AoE** |
| Response granularity | Respond per review; organize by reviewer ID |
| Response limit | **5,000 characters per round.** The author-reviewer discussion has **three rounds — rebuttal, reviewer follow-up, author follow-up — each limited to 5,000 characters** (per the 2026 Reviewer Instructions). |
| Revised paper upload | Not allowed during the author feedback period |
| Discussion flow | Three-round discussion: author rebuttal → reviewer follow-up (with required acknowledgement) → author follow-up. Two official phrasings of the same sequence: the Reviewer Instructions say "three rounds in the author-reviewer discussion (rebuttal, reviewer follow-up, author follow-up), each limited to 5000 characters"; the Author Instructions say reviewers and authors "will be able to engage in one additional round of communication" after the response period. |
| Public record | For every accepted paper, ICML publishes the original submission and supplementary material, anonymized reviews, meta-reviews, **rebuttal**, and reviewer-author discussion alongside the camera-ready. Rejected papers may opt in. |
| Reciprocal reviewing | Designate a qualified author-reviewer for each submission; one person may cover at most 2 of their submissions. Authors on 4+ submissions must review (subject to listed exemptions). Unmet requirements or inadequate reviewing may cause the reviewer's own papers to be desk-rejected. |
| Other mandatory policies | Include an Impact Statement. Prompt injection by authors is forbidden (Reviewer Instructions: "Prompt injection by authors is forbidden"), so a response must never contain text aimed at steering automated reviewers. Treat prompt injection as grounds for desk rejection. Use LLMs only as tools, never as authors, and accept responsibility for their output. |
| Sources | https://icml.cc/Conferences/2026/CallForPapers; https://icml.cc/Conferences/2026/AuthorInstructions; https://icml.cc/Conferences/2026/ReviewerInstructions |

**Write for the public record.** Treat every ICML 2026 response as durable scholarly prose: correct the record precisely, keep the tone professional, and avoid throwaway concessions or promises that conflict with the final paper.

**ICML 2027:** the CFP page (icml.cc/Conferences/2027/CallForPapers) read "will be posted here soon" on 2026-11-12, so no 2027 response rules were available; do not carry the 2026 numbers forward without checking.

### ICML 2025 (historical response mechanics)
| Field | Value |
|-------|-------|
| Platform | OpenReview |
| Response granularity | Per-review response |
| Character limit | **5,000 characters** per response |
| Format | Markdown text |
| File uploads | Not allowed during author feedback period |
| Links/URLs | No non-anonymized/personal/shortened URLs |
| Revised paper upload | Not allowed during feedback period |
| Discussion flow | Author rebuttal → reviewer acknowledgement (required) → limited follow-up round |
| Source | https://icml.cc/Conferences/2025/AuthorInstructions |

ICML 2026 keeps a **5,000-character** cap, now stated per round for the **three discussion rounds** (rebuttal → reviewer follow-up → author follow-up; see the ICML 2026 section above). Confirm the live response form at rebuttal time as usual.

### ICLR 2026
| Field | Value |
|-------|-------|
| Platform | OpenReview |
| Response model | Public discussion with author comments and reviewer interaction |
| Per-comment limit | **Word limit per comment.** The Author Guide confirms a limit exists but does not publish the number; check the comment box in OpenReview. |
| Number of comments | No limit; post multiple replies to each reviewer if useful |
| Timeline (ICLR 2026) | Reviews released **Nov 11**; public discussion and author replies **Nov 11–Dec 3**; private reviewer/AC discussion **Dec 3–Jan 22**; decisions **Jan 22** |
| Revised paper (ICLR 2026) | Revise the paper, title, abstract, and supplementary material through **Dec 3**. OpenReview applies `pdfdiff`; reviewers/ACs may ignore substantially divergent changes. |
| Paper length | **9 pages** at submission; **10 pages** during discussion and for camera-ready |
| Visibility | Reviews are public. All submissions are de-anonymized and released after decisions. Papers withdrawn after the submission deadline remain publicly hosted and are immediately de-anonymized. |
| Reciprocal reviewing | Authors on 3+ papers must review at least 6 papers; failure to finish by rebuttal may risk desk rejection. |
| Discussion model | Iterative — treat it as an evolving public thread, not a terminal message |
| Source | https://iclr.cc/Conferences/2026/AuthorGuide |

## HotCRP Venues

### OSDI 2025 (USENIX)
| Field | Value |
|-------|-------|
| Platform | HotCRP |
| Response cap | **2,000 words** |
| New experiments/data | **Explicitly disallowed** |
| New promised work | Disallowed |
| Review type | Double-blind |
| Source | usenix.org/conference/osdi25/call-for-papers |

### OSDI 2026 and 2027 (USENIX)
| Field | Value |
|-------|-------|
| Platform | HotCRP |
| OSDI '26 | The CFP "Removes the author response period" and replaces revise-and-resubmit with a conditional accept decision |
| OSDI '27 | The CFP lists no author-response period; "Conditional acceptance decisions, no revise and resubmit" |
| Consequence | **No rebuttal to write for OSDI '26/'27.** If the user has an OSDI '26/'27 submission, check the live CFP/portal rather than applying the 2,000-word OSDI '25 rules |
| Review type | Double-blind |
| Source | usenix.org/conference/osdi26/call-for-papers; usenix.org/conference/osdi27/call-for-papers |

### SOSP 2025 and 2026
| Field | Value |
|-------|-------|
| Platform | HotCRP |
| Response | Optional |
| Length guidance | Strongly encouraged **under 500 words** (same wording in the 2025 and 2026 CFPs) |
| Hard cap | "There is no explicit limit"; reviewers are "neither required nor expected to read excessively long responses" |
| New experiments/data | **Disallowed:** responses "must not include new experiments or data, describe additional work completed since submission, or promise additional work to follow" |
| Scope | Limited to (a) correcting factual errors in the reviews or (b) directly addressing questions posed by reviewers |
| Review type | Double-blind |
| SOSP 2027 | No SOSP 2027 CFP was published as of 2026-11-12 |
| Source | sigops.org/s/conferences/sosp/2025/cfp.html; sigops.org/s/conferences/sosp/2026/cfp.html |
